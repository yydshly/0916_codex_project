## 风格之外还可以组合什么

- **配色**：风格规范不绑定固定 HEX；品牌色、浅深底可以按内容另选，但需保持风格一致性。
- **版式与画幅**：本次样本包含 16:9、4:3、A4 和竖版；章节页、图表、说明页可沿用同一视觉语言。
- **内容载体**：原生文字、形状、表格、图表、公式，与照片、插画、纹理组合。风格名称不决定对象是否可编辑。
- **放映效果**：上游还有切换、对象动画与旁白工作流。截图只能展示静态视觉；本研究自己的五页样例验证过淡化切换的文件结构，未端到端复现复杂动画与旁白。
- **定制方向**：可以按参考图、品牌规范或既有 PPT 模板定制；生成质量仍需检查与迭代，不保证任意参考逐像素还原。

毛玻璃是透明度、渐变与层叠等形成的外观，不意味着任意浏览器模糊均能转成 PowerPoint 原生效果。剪纸是层次视觉，不是可旋转 3D。水墨或手写题字可能是图片，原生 PPT 能打开不等于每一笔可编辑。

## 预览证据和复现

案例仓库固定在 `3adb91f1d3226f5a48c2df1d10e1f3f37a246a87`。每个方向选一个官方案例的封面与内容页；作品来自不同主题和创作过程，不是控制变量实验。逐页来源、哈希和风格规范见 [style-catalog.json](../app/style-catalog.json)。

静态预览由 Microsoft Edge 将原始 SVG 作为图片渲染，保留完整画面。未把所有官方 PPT 在 PowerPoint 中逐份渲染，因此它们和首页五页本地实测的证据等级不同。字体可能受 Windows 本地替换影响。适用场景和编辑边界说明是本研究归纳。

复现：先将官方 examples 仓库克隆到根目录已忽略的 `upstream/ppt-master-examples/`，确保含上述提交。然后从根目录执行：

```powershell
python projects/001-ppt-master/scripts/collect_styles.py
# 需要 Node.js、Playwright 与已安装的 Microsoft Edge；依赖在本子项目内自行管理。
node projects/001-ppt-master/scripts/render_styles.cjs
```

收集脚本将源 SVG 缓存到 `upstream/ppt-style-cache/`；渲染脚本生成 `app/style-previews/` 和 [预览记录](../app/style-preview-evidence.json)。本次使用宿主提供的 Playwright，无需修改总仓库依赖。
