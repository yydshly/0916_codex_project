## 结论

完整讨论结论见 [我们的最终理解](notes/understanding.md)。本次研究已结束，保留编号、记录、网页与总览图，不再继续功能复刻或工具集成研究。

固定版本根文件树只有 `README.md`。该项目提供方法、提示示例和外部资源导航，没有可运行的应用、模型执行器、SDK、自动测试或部署服务。

最值得借鉴的主线是：明确需求 → 拆分任务 → 约定规则 → 逐项实现 → 验证结果。代码生成和测试执行仍需外部编程工具与运行环境。六类能力和网页六步讲解是本研究归纳，不是上游正式模块划分。

结合我们当前已经使用 Codex、AGENTS.md 与项目检查流程的情况，**本库属于低优先级参考，新增价值有限，没有独立功能可直接集成或复刻**。对新手的主要价值是建立全貌与学习协作方法；我们仍需要提供业务目标、项目约束和验收标准，但不需要引入该库才能做到。

## 实际参考价值

当前总仓库已经有 AGENTS.md、固定编号、项目清单和检查流程。可借鉴指南，将每次研究连接成“研究问题 → 观察计划 → 实际证据 → 结论边界”，并保留后续接手者需要的上下文。现有 README 和 notes 目录即可承载，无需引入全仓库框架。

新项目先走通最小用户流程；旧项目按具体变更提供相关上下文；反复报错时增加复现步骤、期望与实际结果。后两者的具体案例是我们的应用建议，不是上游软件功能。

## 运行与构建

使用原生 HTML / CSS / JavaScript；无第三方前端依赖、无密钥、无安装步骤。

在仓库根目录预览该子项目：

```powershell
python -m http.server 8788 --bind 127.0.0.1 --directory projects/008-aicodeguide/app
```

访问 `http://127.0.0.1:8788/`。主页面支持流程按钮切换、来源跳转和移动宽度布局；静态文字版不依赖脚本。

使用总仓库现有构建：

```powershell
python scripts/projects.py sync
python scripts/projects.py check
node --check projects/008-aicodeguide/app/app.js
python scripts/build_web.py
```

构建后入口为 `web/008-aicodeguide/index.html`。资源使用相对链接，支持后续 GitHub Pages 子路径托管；**尚未公开部署**，`projects.json` 的 `demo` 保持为空。遵循 [部署约定](../../docs/DEPLOYMENT.md)。
