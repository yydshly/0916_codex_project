# 005 · Fridge Magnet 磁贴墙与个人记录研究

> 最值得复用的是有材质、有操作反馈、能区分关注重点的面板呈现层。可接入已有成长记录、反思、作品与个人项目软件；现已完成自主概念演示，真实业务接入仍是后续方案。

## 我们的理解

1. **从好看走向好用**：材质、景深、拿起与落下反馈让内容有体感；焦点／重点／稍后划分帮助用户知道先看什么。重要度由用户选择，不能只有颜色差异。
2. **面板接入已有软件**：记录、任务与媒体由原来的系统管理，面板提供陈列、详情入口和操作反馈。当前不是可安装的通用组件库，也未确认原站是否开源。
3. **同一份内容，面向不同场景**：成长墙留住经历，反思墙回看问题，作品墙展示成果；项目板、今日板与日报共用任务编号，日报保留历史快照。关注级别、任务状态、计划日期分别表达不同事情。
4. **先完成记录闭环，再扩展协作**：成长记录贴吧可从家庭私密墙开始；个人工作台先接已有任务，再做明确的状态／日期操作与可靠保存，最后连接日报和周复盘。

## 网页展示

入口：[磁贴墙体验与扩展方向](app/index.html)。页面为自主编写的概念演示，不是原站源码或上游库的调用结果。

- **默认成长墙**：童言童语、第一次、画作、日常与写给未来的信；照片位使用 AI 示例插画。
- **四种场景**：孩子成长、个人反思、作品展示、原站竞价逻辑；每种场景 6 张虚构卡片。
- **六种风格**：复古冰箱、软木手账、蓝图网格、极简展馆、深夜玻璃、彩色积木；可独立切换面板与卡片材质、固定件、阴影及悬停效果。
- **交互**：展开故事、拖动卡片顶端、方向键移动、注意力分层、专注模式、撤销级别调整、还原摆放，以及竞价滑块。
- **方向汇总**：成长、反思、作品、家庭、学习、社区，以及项目规划、每日工作、项目日报、周计划复盘、灵感孵化与生活筹备，共十二类。
- **项目与日报方案**：项目板看全局、今日板做事情、日报时间线看积累；通过同一条虚构任务解释共用数据与历史快照。
- **产品路线**：记录场景从私人保存发展到家庭协作与回顾；工作台先对接已有任务，再增加状态/日期操作，最后关联日报与周复盘。

三个个人场景按注意力分层，原站场景仍按出价展示。页面不接收真实儿童照片或个人记录，没有上传、账号、存储、支付、真实链接提交或家庭分享功能。刷新会还原全部示例状态。

### 注意力层次：让用户知道先看什么

- **当前焦点**：最多一张，使用更大的面积、完整摘要、明显边框和独立区域，避免所有内容同时争夺注意力。
- **重点关注**：放在旁边，保留标题和摘要；缩略图与信息密度降低，内容仍可读、可展开。
- **稍后再看**：默认收进可展开列表，保留数量与标题；不是删除或业务归档。
- 卡片底部和详情里可直接选择关注级别。设置新焦点时，原焦点降为重点，不丢失内容。
- **只看焦点**暂时隐藏其他区域，一键恢复全览；没有焦点时不可进入专注模式。
- 可撤销当前场景最近一次级别调整。变更级别时重新排布卡片，撤销时恢复此前级别与摆放；不同场景独立保留本次浏览的选择。
- 成长场景明确说明：分层代表此刻想回看什么，不是给孩子或记忆评分。原站竞价不受个人关注层次影响。

模型在 `attention-model.js`，视觉在 `attention.css`；使用真实的区域、尺寸、文本标签与渐进展开表达重要度，不仅靠颜色，也不通过持续闪烁制造紧迫感。单焦点、分组不丢记录、稍后恢复等规则由 `notes/verify-attention.cjs` 验证；浏览器已检查级别调整、撤销、专注、详情与稍后恢复。

详细整理：[个人价值与扩展方向](notes/extension-directions.md)。

| 风格 | 面板与卡片表现 | 操作反馈 |
| --- | --- | --- |
| 复古冰箱 | 搪瓷光泽、胶带、错落纸卡 | 轻微抬升与放大 |
| 软木手账 | 颗粒底板、木色边框、圆头图钉 | 悬停纸张转正、柔和长阴影 |
| 蓝图网格 | 蓝色细网格、直角索引卡、顶部标签 | 硬边投影与轮廓强调 |
| 极简展馆 | 浅灰留白、窄深色画框、平直排列 | 放大悬浮与柔和投影 |
| 深夜玻璃 | 深色渐变、半透明卡片、微光边缘 | 微光与悬浮；不支持背景模糊时使用实色回退 |

风格实现放在独立的 `app/panel-themes.css` 与 `app/panel-themes.js`，通过 `body[data-panel-theme]` 切换，不修改场景数据、关注级别和拖动位置；切换内容场景时保留风格，刷新恢复默认。已提供触控布局、键盘选择和减少动态效果的样式。这里仍是独立演示的呈现层，尚未封装为可安装的通用组件库。

### 材质与操作反馈

新增独立的 `panel-physics.js`、`panel-feel.js`、`panel-feel.css`：

- **拿起与拖动**：卡片增加景深和投影，拖动方向与速度影响倾斜；移动范围受面板边缘约束。
- **复古冰箱**：原位附近 25 像素内松手吸回原位；不是卡片之间的碰撞或全局磁力模拟。
- **软木手账**：以顶部图钉为轴，松手后产生逐渐减弱的摆动。
- **蓝图网格**：移动时展示水平/垂直参考线，松手后按相对原位的 20 像素步进对齐。
- **极简展馆**：光斑跟随鼠标，画框拿起时浮离底板。
- **深夜玻璃**：随鼠标位置倾斜和反光，落下时产生短暂涟漪。
- **彩色积木**：松手后横向挤压、纵向伸缩，再阻尼回弹。
- **演示按钮**：“感受一下”用首张卡片演示当前材质，不修改数据或摆放位置。
- **可选合成音**：默认关闭，用户开启后在落下时播放短促音色；不是实际材质录音，不申请麦克风权限。
- **减少动态效果**：首次遵循系统偏好，也可手动关闭；键盘仍可移动卡片。触屏可拖动与放下，鼠标悬停反光与追光不等同于硬件触觉反馈。

动画在切换场景、风格及页面隐藏时停止；单次弹簧动画最长 1.7 秒，不使用持续空转的全局动画循环。

## 本地运行与构建

技术：原生 HTML / CSS / JavaScript，无依赖安装和独立前端框架。使用系统字体与本地插画，不依赖外部字体、统计脚本或图床。

从总仓库目录运行：

```powershell
python -m http.server 9505 --bind 127.0.0.1 --directory projects/005-fridgemagnet/app
```

访问 `http://127.0.0.1:9505/`。四个页面状态使用 `#wall`、`#workbench`、`#possibilities`、`#blueprint`，可直接打开和刷新。也可直接用浏览器打开 `app/index.html`。

`#workbench` 为新增描述与示意，尚未实现真实项目状态流转、日期落点、任务分组、日报生成或数据保存；现有磁贴拖动仍只调整视觉位置。

接入仓库统一静态构建：

```powershell
python scripts/projects.py sync
python scripts/projects.py check
python scripts/build_web.py
```

构建会生成 `web/005-fridgemagnet/` 并在总入口增加按钮。依据[部署约定](../../docs/DEPLOYMENT.md)，实际发布并验证后才填写线上链接。

## 它能做什么

它是一个具有复古冰箱外观的付费网站链接展示平台。用户提交链接和出价，访客通过冰箱贴访问对应网站。其直接用途是给产品、个人网站或社区提供曝光入口；实际引流与转化效果尚未验证。

| 能力 | 具体表现 | 证据与验证边界 |
| --- | --- | --- |
| 网站链接展示 | 首页卡片展示网站图标、名称、简介、出价与排名，可链接到对应网站 | 已观察首页卡片与链接；未验证内容抓取和更新机制 |
| 提交链接及出价 | 提交表单包含链接、整数美元出价以及预计位置提示 | 已观察表单控件；未提交订单或验证预测准确性 |
| 按出价安排位置 | 官网说明最高出价居中，前 15 名在门上，其余保留在冷冻室 | 已阅读规则；当前未实测超过 15 个条目的表现 |
| 追加出价 | 官网说明可为自己的磁贴继续加价，出价只能上升；被超过不因此删除 | 已阅读规则；未验证身份校验、补价计算或支付流程 |
| 外观定制 | 提交表单提供磁贴颜色选择 | 已观察颜色控件；未购买验证最终呈现 |
| 公开统计与动态 | 首页显示磁贴数量、售出金额、浏览计数及近期上架、加价记录 | 已观察界面；统计口径、去重和实时更新机制未确认 |
| 下架联系渠道 | 官网列出非本人提交、冒用、违法或恶意链接的联系邮箱与处理说明 | 已阅读说明；未测试响应速度或处理结果 |

官网规则说明：最低 1 美元、整数美元出价、一次付款、无订阅、不退款。展示持续时间取决于网站运营与域名续费，不应理解为永久展示保证。以上为规则转述，未实际购买。

## 值得研究的地方

- **展示设计**：冰箱门、拍立得卡片、磁贴、计数器和纸质账单共同承载展示、排名、统计与活动记录。
- **排名与收费的结合**：把有限的显眼位置与出价绑定，并通过预计排名帮助用户理解购买结果。
- **访问路径**：访客从浏览磁贴进入外部网站；适合进一步观察曝光、点击和付费展示之间的关系。

这些是基于页面的研究方向，不构成商业效果或技术先进性的结论。
