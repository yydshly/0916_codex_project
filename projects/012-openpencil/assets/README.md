## 引导图制作提示

使用内置 imagegen，制作一张 3:2 横版中文研究信息图，白底、深蓝字、钴蓝强调，文字清晰、留白充分，不伪造软件截图。

标题“OpenPencil：能力、效果与意义”，副标题“可被 Agent 操作的开源设计编辑器”。三个栏目：

1. 能力是什么：软件本体（画布、图层、矢量与布局）；Agent 接口（MCP / CLI）；配套 Skill（操作方法与规则）。
2. 效果偏向什么：已测效果传统、规整、商务；典型样本为后台工作台与数据汇报；不等于只能生成这种风格。
3. 意义在哪里：让设计稿可定位、可修改、可保存；适合研究设计自动化与批量制作；创意与审美质量仍需单独验证。

五步箭头：需求 / 脚本 → 工具调用 → 可编辑节点 → 布局渲染 → 保存 / 导出。

验证条：92 节点工作台、修改与回读、保存文件、PNG 导出。底注明确内置 AI 未测试，商务倾向来自本次模板与外部 Agent 样本，不代表生成上限。署名“原创研究引导图 · v0.8.4 本地实测 · 2026.09.17”。
