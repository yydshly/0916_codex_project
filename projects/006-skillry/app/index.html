低优先级的技能资源与视觉流程参考站。现阶段不建议仅为目录付费，也不继续投入大规模评测。可以参考分类方式、案例风格和工作流说明；是否值得购买，应看具体技能的独有价值。

05 / GET STARTED

从一个明确的交付物开始。

把“做得好看”换成具体输入与验收要求，更容易判断技能是否适用。

  1. 先定产物

    是能在浏览器打开的页面、可编辑演示文件、一张插图，还是可播放的视频？明确格式、尺寸和使用场景。

  2. 核对一个技能的详情

    看 What you get、You bring、Dependencies 和 Not for，比较样例与你的目标是否一致。不要只按标题或评分选。

  3. 连接账号，按说明安装

    使用官网安装提示或 CLI 的浏览器授权；免费技能也需要登录。目录位置与步骤以该技能的安装指南为准。

    官方安装指南 ↗

  4. 提交真实素材和约束

    提供已确认的文字、数据、品牌元素与参考。说明哪些内容必须保留，哪些地方可以让 AI 自由设计。

  5. 检查文件，再判断是否复用

    实际打开产物，检查内容准确性、格式、资源、可编辑性和外部用量。视觉满意后，仍要确认文件能在目标环境中使用。

06 / OUR USE CASES

放到我们的研究仓库里，怎么用？

以下是应用建议，不是已经完成的技能实测。

场景 A / 研究展示

把研究记录做成网页

把项目摘要、实际截图与验证结论交给网页技能，形成介绍页或作品集。

检查重点事实是否准确、资源路径是否可用、手机阅读是否方便。
场景 B / 汇报交流

把结论整理成演示

先明确听众和结论，再选演示技能；需要 PPTX 时单独规划导出和验证。

检查重点原生文本、图表、公式的可编辑性，以及字体和版式保真。
场景 C / 内容传播

给项目补充视觉素材

为技术说明配图，或用真实界面制作短片。先确认素材和信息，再决定风格。

检查重点生成成本、品牌一致性、素材授权，以及能否保留源文件。
后续按需再看

暂不安排进一步安装和评测。如果遇到明确需求，再选择单个技能与免费方案做同题对照，检查内容质量、可编辑性、时间与成本。当前没有比较结果。
