# 006 · Skillry 创作技能能力图谱

> 面向网页、演示文稿、图片与视频的技能分发网站。将官方公开资料整理为中文网页，明确输入、产物、依赖和能力边界。未下载或执行任何 Skillry 技能。

## 我们的理解与取舍

**本质是偏视觉创作的 Skill 展示、售卖和分发平台。** 网站提供分类浏览、案例、获取与更新入口；实际产出来自技能方法、宿主 AI 助手和外部工具的组合。尚未确认它拥有独立在线创作引擎、自研模型或通用自动化平台。

对本仓库而言，定位为**低优先级资源参考**：保留技能分类、案例风格和工作流说明的参考价值；现阶段不建议仅为目录付费，不继续安排大规模安装和评测。

收费是否合理，应看具体技能是否有原创流程、脚本、实测和持续维护。我们没有核查私有技能包来源、原创程度与免费替代，不能认定其在转售免费技能，也不能证明付费内容明显更好。详见 [讨论结论](notes/understanding.md)。

## 网页展示

入口：[app/index.html](app/index.html)。包含八个完整章节：能力总览、四类技能、官方案例与交付物、工作原理、从选择到交付、仓库场景、费用与边界、来源与资料下载。

使用 HTML / CSS 与少量原生 JavaScript，无额外依赖、不调用模型。锚点导航和 details 展开无需 JavaScript；脚本仅增强当前章节标记和视频错误提示。移动端使用单列内容和可横向滚动的对照表。页面不要求账号，不收集或存储用户信息。

补全内容包括 4 张官方案例预览、官网视频播放入口、12 个代表技能详情链接、5 步开始流程、需求示例，以及研究笔记、能力图和来源记录下载。图片保存为本地缩略预览；视频保留官方公开地址，点击播放时才加载，不能离线观看。官方展示不代表本地运行结果。

仓库根目录运行：

```powershell
python -m http.server 8778 --bind 127.0.0.1 --directory projects/006-skillry/app
```

访问 http://127.0.0.1:8778/ 。也可直接打开 HTML 文件。

接入现有演示总入口：

```powershell
python scripts/projects.py sync
python scripts/projects.py check
python scripts/build_web.py
```

构建产物位于 web/006-skillry/，总入口自动显示“浏览能力图谱”。

# 我们对 Skillry 的理解与取舍

讨论整理：2026-09-16。研究对象仅为 [skillry.dev](https://skillry.dev/)，尚未确认其官方开源代码仓库。

## 本质：偏视觉创作的 Skill 目录与分发平台

网站把技能按产物分类，提供案例展示、说明、账号授权、购买、安装分发与更新。我们使用“收录”描述目录中的条目，不据此断言所有技能都是从别处收集而来；技能的原始作者、原创程度及改造情况尚未核实。

要区分平台功能与技能运行能力：网站帮助用户找到并获取技能；技能提供任务方法、规则与配套资源；真正生成文件的是宿主 AI 助手和相应工具。没有从本次公开资料中确认网站另有自研模型、独立在线创作引擎或通用自动化执行平台。

## 主要收录哪类、哪些、哪方面的技能

下列数量来自 2026-09-16 的[目录快照](https://skillry.dev/skills)，不是完整功能的实测数量。每类只列代表条目；目录内同时存在整页、组件、风格模板等不同粒度。

| 类别 | 主要方面 | 代表技能 | 输出与边界 |
| --- | --- | --- | --- |
| 网页 Web · 86 | 产品落地页、开发者作品集、首屏、图表与数据展示 | Obsidian Cinema Landing；Editorial Dev Portfolio；Activity Calendar Chart | 页面或组件代码；不自动包含业务后端、支付或上线 |
| 演示 Slides · 47 | 产品路演、品牌故事、研究汇报、论文演示 | Visual Canvas Deck；Editable Visual Deck；Research Paper Deck | 演示页面或文件；原生可编辑 PPTX 需另行核对 |
| 图片 Image · 81 | 文章插图、分享封面、品牌视觉、信息图和人像 | Paperline Content Illustrator；Procreate Style OG Image；Monochrome Studio Portrait | 视觉图片；部分技能需要外部模型、账号和额外费用 |

这些能力集中于内容制作、视觉表达和产品传播，不应据条目数量将其理解为覆盖所有开发、研究和业务工作的通用能力库。代表条目的原始链接见网页四类技能卡片；四个抽查版本和依赖见子项目 README。

## 收费是否值得

我们对目录收费的价值持保留态度，但不能从“收费”直接推出“转售免费技能”。Skill 是一种内容组织方式，并不要求所有内容免费；收费也不证明质量高。

- 如果只是整理免费链接与分类，对我们附加价值较低，可以优先查找原作者和免费来源。
- 如果包含原创工作流、实用脚本、可信的验证和持续维护，可能有付费价值，需要查看具体内容及对照结果。
- 如果重新包装现成免费内容却不清楚说明来源和改动，应认真质疑其价值；本项目没有取得这类情况的证据，不能将其写成对 Skillry 的事实指控。

目前未检查私有技能包，也未做免费替代对照，不能证明其付费内容明显优于免费选择。

## 我们的结论

定位为**低优先级的技能资源与视觉流程参考站**，保留目录分类、案例风格、输入／输出／依赖描述的参考价值。现阶段不建议仅为目录付费，也不继续投入大规模安装和评测；如遇到明确需求，再研究一个具体技能是否有独有价值。

这是一项结合当前需求作出的取舍，不是“对所有用户没有价值”的普遍结论，也不是对原创性或商业行为的定性。
