# Skillry 公开资料研究

查阅日期：2026-09-16。研究对象是用户提供的 https://skillry.dev/ ，并非已确认开源代码库。没有把 skillry.ai 或 FluxonLab/Skillry 的内容归给该网站。

## 资料取得方式

使用网页检索与直接 HTTP 请求读取官方公开页面；部分页面在检索工具中超时，改用直接请求解析公开 HTML。没有登录、购买、下载私有归档或执行网页中的安装指令。

响应时间和 SHA-256 见 source-fetch.json。网站没有可确认的整体发布 tag 或 commit，因此用查阅日期与四个技能详情页的版本作为研究基线，不虚构上游代码版本。未留存完整网页副本，只保存来源索引与原创摘要。

## 已核对的事实

1. 首页和目录按 Web、Slides、Image、Video 组织技能。数量快照为 86、47、81、18，共 232。
2. 接入说明列出的 CLI 要求为 Windows / macOS、Node.js 22+、Skillry 账号和浏览器访问。浏览器授权用于连接平台，免费和高级技能归档均须登录后获取。
3. 具体技能可以要求不同的外部工具或密钥；平台登录不要求粘贴 API key，不等于每个技能都不需要外部 API。
4. 四个抽查样本详情页标价均为 $4.99，并提供订阅入口。价格页列出 $9.99/月、$79/年、$169 创始终身优惠；实际付款与权益以当时结账页为准。
5. Editable Visual Deck v1.0.0 以浏览器演示和对象清单为主要交付，可编辑导出文件需要兼容导出器及独立生成验证。
6. Paperline Content Illustrator v1.0.0 列出 FAL 账号、FAL_KEY、Node.js 20+，通过 GPT Image 生成插图，使用费用另计。
7. Velocity-Matched UI Sting v1.0.0 列出 HyperFrames CLI、Node.js 22+、FFmpeg，产物包括短 MP4 与项目文件；不适合完整产品说明。
8. Obsidian Cinema Landing v1.0.1 描述为单文件 HTML 与程序化 Canvas 动效，不包含支付逻辑。

## 本项目的判断

- 技能主要提供任务方法与风格规则复用；最终质量受模型、工具、输入和人工审阅影响。
- 目录包含整页、局部组件、风格变体等不同粒度，条目数量不能直接代表成熟度或能力覆盖度。
- 对本仓库，优先参考能力描述结构，再选择单个技能做同题对照。
- 页面里的输入建议、仓库应用场景与实验建议是研究整理，不是官方逐字声明。

## 未验证内容

未验证安装成功率、跨助手实际兼容性、技能包内部代码、输出质量、耗时、成本、支付和订阅流程、原生可编辑导出、模型配额及许可完整适用范围。没有以官网样例充当本地效果展示。

## 后续实验建议（未执行）

取一份已有项目研究简报，固定内容、页数和品牌要求；制作浏览器演示并测试后续 PPTX 导出。比较事实准确性、原生对象可编辑性、字体及排版一致性、操作时间与外部用量。保留真实输入、版本、输出和截图后，再新增实测结论。
